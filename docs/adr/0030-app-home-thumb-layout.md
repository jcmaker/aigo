# 0030. 홈에서 사고 현장 모드를 엄지가 닿는 아래쪽 전체 폭 버튼으로 옮긴다

- 상태: 제안
- 날짜: 2026-11-14
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #번호

## 작업 내용
홈 화면 배치를 사고 현장에서 한 손으로 쓰기 좋게 바꿨다(`app/(tabs)/home.tsx`).

- 사고 현장 모드: 왼쪽 위 빨간 카드 → 화면 아래쪽(하단 메뉴 바로 위) 전체 폭의 큰 빨간 버튼(높이 76 이상, 아이콘·제목·설명·화살표). 바탕을 진한 빨강(`danger600`)으로 바꿔 흰 글씨 대비 5.28:1, 설명 4.76:1이 되게 했다.
- 분석 결과 카드: 없앴다. 분석이 있을 때만 맨 위에 "최근 분석" 1건과 "전체 보기"를 보인다(기존 `RecentAnalyses`에 `limit`·`title`을 더해 재사용). 0건이면 아무것도 보이지 않는다. 전체 목록은 하단 "내 분석" 탭에 있다.
- 영상 분석 카드: 최소 높이 280 → 220, 카메라 원 96 → 64. 최근 분석 줄이 보일 때는 카메라 원을 빼서 작은 화면(320×640)에서도 사고 현장 모드 버튼이 스크롤 없이 보이게 했다.
- DashPi 기기(준비 중): 큰 카드 → 작은 한 줄.

## 변경 사유
이 앱은 뒤처리가 중심이지만 사고 현장에서 당황한 사용자에게 도움을 줘야 한다. 오른손잡이가 대부분인데 사고 현장 모드가 한 손 엄지가 가장 닿기 어려운 왼쪽 위에 있었고, 분석 결과는 영상을 올린 뒤에야 보는 것이라 첫 줄을 차지할 필요가 없다. - 최혜지

오른쪽 절반이 아니라 아래쪽 전체 폭으로 둔 것은, 사고 현장에서는 어느 손으로 폰을 들지 모르기 때문이다(왼손잡이·왼손으로 든 경우 포함).

## 영향
- 기능과 화면 이동은 바뀌지 않았다. 사고 현장 모드 버튼은 이전과 같은 `/emergency`로 간다.
- ADR 0028·0029 브랜치 위에서 작업했다. 0028 → 0029 → 0030 순서로 머지되어야 한다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(108개 통과). 웹 빌드로 390px·320px, 분석 없음/있음 네 경우를 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
