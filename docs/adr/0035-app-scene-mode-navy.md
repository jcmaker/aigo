# 0035. 사고 현장 모드를 남색·민트로 맞추고, 112·119 버튼을 아래에 고정하되 확인 창을 거치게 한다

- 상태: 제안
- 날짜: 2026-11-22
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #98

## 작업 내용
사고 현장 모드 화면(`components/SceneBody.tsx`, `components/SceneGuide.tsx`)의 색과 배치를 바꿨다. 질문 순서와 안내 문구(`lib/scene-guide.ts`, ADR 0025)는 바꾸지 않았다.

- 머리글: 흰 바탕 제목줄과 오른쪽 위 빨간 "신고" 버튼 → 리포트·내 분석과 같은 남색 머리글(`ReportHeader`). 아래 줄에 "로그인·인터넷 없이 쓸 수 있어요"(ADR 0017).
- 질문 카드: 하늘빛 파랑(`sceneCard` #5580C8) → 남색(#1A2B4C, `ink`와 같음). 진행 막대는 민트, 누른 선택지 바탕은 연한 민트(`mintSoft`), 선택지 설명 글씨는 15px로 키웠다.
- 지금 할 일: 완료 체크 바탕을 파랑(`brand`) → 진한 민트(`mintDeep`, 흰 체크). "n/6 완료", "다시 답하기", 자세한 방법 글씨(14 → 15px)도 맞췄다. 급한 단계의 연분홍 상자는 위험 표시라서 그대로 둔다.
- `Card`의 오른쪽 위 글씨(action) 색을 파랑 → 진한 민트로 바꿨다. 지금 이 글씨를 쓰는 곳은 사고 현장 모드(지금 할 일, 알릴 사람)뿐이다.
- 현장 도구: 세로로 늘어선 "현장 사진 촬영" 버튼과 "찍은 사진 보기" 줄을 2×2 타일로 묶었다(현장 사진 촬영, 찍은 사진 보기, 보험사 전화, 알릴 사람). 보험사 번호가 없으면 "보험사 전화"는 아래 보험사 카드로, "알릴 사람"은 알릴 사람 카드로 화면을 내린다.
- 신고: 오른쪽 위 버튼 → 화면 아래(하단 메뉴 바로 위, 하단 메뉴가 없는 진입에서는 맨 아래)에 "112 경찰 신고", "119 구급·소방" 빨간 버튼 두 개를 고정했다(`danger600`, 흰 글씨 대비 5.28:1). 스크롤해도 같은 자리에 있고, 사고 현장 모드 화면에만 있다.
- 확인 창: 아래 고정 버튼을 누르면 바로 전화 앱을 열지 않고 "112 경찰에 전화할까요?" 창을 띄운다. "112에 전화 걸기"를 눌러야 전화 앱이 그 번호로 열리고, "취소"나 바깥을 누르면 닫힌다.
- 고정 버튼에 가리지 않게 화면 맨 아래 여백을 더 두었다.

## 변경 사유
사고 현장 모드 UX/UI 수정 - 최혜지

리포트·홈·내 분석을 남색·민트로 바꾼 뒤 사고 현장 모드만 하늘빛 파랑이라 다른 앱처럼 보였다. 가장 급한 신고 버튼이 한 손 엄지가 닿기 어려운 오른쪽 위에 있어서, 홈의 사고 현장 모드 버튼(ADR 0030)처럼 아래로 옮겼다. 아래에 늘 떠 있는 버튼은 스크롤하다 잘못 누르기 쉬워서, 바로 전화가 가지 않게 확인 창을 한 번 거치게 했다(최혜지 요청).

## 영향
- 기능, 화면 이동, 서버 API, 오프라인 동작은 바뀌지 않았다. 질문 흐름과 안내 문구도 그대로다.
- "지금 할 일" 단계를 펼쳤을 때 나오는 112·119 바로가기는 지금처럼 확인 창 없이 전화 앱을 연다(단계를 펼쳐 한 번 더 누르는 동작이라 잘못 누를 일이 적다).
- 아래 고정 버튼과 하단 메뉴가 화면 아래를 함께 차지해, 스크롤하는 동안 가려지는 부분이 늘었다.
- 보험사 번호 입력 카드는 그대로 두었다. 번호를 저장하면 입력칸을 숨기는 것은 다음 작업이다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(120개 통과. 신고 테스트를 "확인 창을 거친 뒤에만 전화 앱을 연다"로 바꾸고, 현장 도구 타일 테스트를 추가). 웹 빌드로 첫 화면, 질문 카드, 지금 할 일, 확인 창을 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
