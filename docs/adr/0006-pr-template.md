# 0006. PR은 배경, 할 일, 한 일, 검증, 작업자로 쓴다

- 상태: 채택 (ADR 0001의 PR 양식 부분을 대체)
- 날짜: 2026-11-09
- 변경 작업자: 조준형 (jcmaker)
- 관련 PR: 비밀값 검사 PR

## 작업 내용
- PR 양식(`.github/pull_request_template.md`)의 칸을 배경(변경 사유), 할 일, 한 일(작업 내용), 검증, 작업자, ADR로 바꿨습니다.
- PR 가드레일이 다섯 칸(배경, 할 일, 한 일, 검증, 작업자)을 확인합니다. 하나라도 비면 실패합니다.
- `CONTRIBUTING.md`에 "PR 쓰는 법"을 넣었습니다: 제목 형식, 칸별 좋은 예와 나쁜 예, 한 PR에 한 가지 일, 전/후 스크린샷.
- `AGENTS.md`의 AI 도구 규칙도 같은 양식으로 맞췄습니다. 실제로 돌리지 않은 검사를 돌렸다고 쓰지 않게 했습니다.

## 변경 사유
비개발자 팀원도 리뷰하기 좋은 PR을 쓰게 하려는 조준형의 요청입니다. "왜, 무엇을, 어떻게 확인했는지"가 나뉘어 있으면 관리자가 코드를 열기 전에 판단할 수 있습니다.

## 영향
- ADR 0001의 "작업 내용, 변경 사유, 작업자" 세 칸은 배경, 한 일, 작업자 칸으로 이어집니다.
- 이 양식 이전에 열린 PR은 PR 본문을 고치면 다시 검사합니다.
