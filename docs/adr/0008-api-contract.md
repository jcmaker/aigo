# 0008. API 계약: /api/v1과 OpenAPI 타입

- 상태: 채택
- 날짜: 2026-11-05
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 2026-11-05 4장, PR #2, #5

## 작업 내용
- 모든 경로는 `/api/v1`로 시작합니다. FastAPI의 OpenAPI 문서가 계약이고, 웹과 앱의 TypeScript 타입은 여기서 생성합니다(`apps/web/openapi.json`).
- 오류 응답은 항상 `{"code": "...", "message": "사용자에게 보여 줄 한국어 문장"}`입니다. 클라이언트는 `code`로 분기합니다.
- 목록은 `?limit=&offset=`을 받고 `{"items": [...], "total": n}`을 돌려줍니다. 시간은 UTC ISO 8601, 금액은 원 단위 정수입니다.
- 다른 사용자의 주문이나 분석을 요청하면 403이 아니라 404를 돌려줍니다.
- 분석 진행 상태는 3초 폴링으로 받습니다. SSE는 쓰지 않습니다.
- 큰 영상은 api를 거치지 않고 서명 업로드 URL로 Bucket에 바로 올립니다(`POST /analyses` → PUT → `POST /analyses/{id}/submit`).

## 변경 사유
- 조준형이 "나중에 모바일 앱을 붙일 수 있게 API를 제대로 구성하라"고 정했습니다. 웹은 API의 첫 번째 클라이언트일 뿐입니다.
- 폴링은 웹과 앱에서 똑같이 동작하고 더 단순합니다.
- Clerk 토큰은 약 1분이면 만료되어, 큰 파일을 api로 받으면 업로드 중에 인증이 끊길 수 있습니다.
- 남의 자원에 404를 주면 그 자원이 있는지조차 알 수 없습니다.

## 영향
- API 응답을 바꾸면 `openapi.json`과 웹·앱 타입을 다시 만듭니다.
- 웹에서만 되고 앱에서는 쓸 수 없는 API는 실패로 봅니다.
