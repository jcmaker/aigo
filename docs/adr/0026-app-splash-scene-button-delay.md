# 0026. 앱 시작 화면의 사고 현장 모드 버튼은 로딩이 늦을 때만 보이고, 로고를 0.8초 더 보여 준다

- 상태: 제안
- 날짜: 2026-11-12
- 변경 작업자: 최혜지 (marong9087)
- 관련 PR: #번호

## 작업 내용
- `apps/app/src/app/index.tsx`: 시작(로딩) 화면 아래의 "사고 현장 모드" 버튼을 처음부터 그리지 않는다. 화면이 열린 뒤 3초가 지나도 로그인 서비스(Clerk)가 로드되지 않았을 때만 버튼을 보인다. 그 전에 로드되면 버튼 없이 기존처럼 로그인 화면이나 홈으로 넘어간다.
- `apps/app/src/components/ui/Splash.tsx`: 진입 모션(1.4초)이 끝난 뒤 완성된 로고를 0.8초 더 보여 준다. 시작 화면이 끝나는 시점이 1.4초에서 2.2초로 늘었다.
- `apps/app/src/components/ui/splash.test.tsx`: 바뀐 시간(2.2초)과 버튼 조건(로드되면 버튼 없음, 로딩 중에는 3초 뒤에만 보임)에 맞게 테스트를 고쳤다.

## 변경 사유
요청: 최혜지 (marong9087).
로그인할 때 시작 화면에 사고 현장 모드 버튼이 굳이 없어도 되는데 계속 떠 있어 거슬리고 깔끔하지 않다. 로딩이 늦을 때만 버튼이 나타나게 하고, 로딩 화면은 0.8초 정도 늘리며, 3초에서 5초가 넘어가면 버튼이 나타나게 해 달라는 요청이었다.
버튼을 완전히 지우지 않은 이유: 인터넷이 안 되면 Clerk가 끝까지 로드되지 않아 앱이 시작 화면에 머문다. 이때 이 버튼이 사고 현장 모드로 가는 유일한 길이다(ADR 0025). 사고 현장은 터널, 지하주차장처럼 인터넷이 약한 곳일 수 있다.
요청 범위(3~5초) 중 3초를 고른 이유: 사고 현장에서는 빨리 들어가는 것이 중요하다. 시작 화면은 2.2초에 끝나므로, 정상 로딩이면 3초 전에 다음 화면으로 넘어가 버튼을 보지 않는다. 시간은 `index.tsx`의 `SCENE_BUTTON_DELAY` 한 곳에서 바꿀 수 있다.

## 영향
- 온라인에서 앱을 열면 시작 화면에 버튼이 보이지 않는다.
- 오프라인이거나 로딩이 늦으면, 화면이 열린 뒤 3초부터 "불러오는 중..." 아래에 버튼이 나타난다. 그 사이 로드가 끝나면 다음 화면으로 넘어간다.
- 앱을 새로 시작할 때 시작 화면이 0.8초 길어진다(1.4초 → 2.2초). 다시 마운트될 때는 지금처럼 모션을 건너뛴다.
- 로그인 화면(`sign-in.tsx`)과 공유 화면(`share.tsx`)의 사고 현장 모드 버튼은 바꾸지 않았다.
- 확인: 앱 타입 검사와 테스트 통과. 로컬 웹 미리보기에서 Clerk가 로드되지 않는 상태로 버튼이 2.9초에는 없고 3.3초에는 나타나는 것을 확인했다. 갤럭시 실기기에서는 확인하지 않았다.
