# 0026. 앱 시작 화면: 현장 모드 버튼은 로딩이 늦을 때만 보이고, 로고 배치와 로딩 표시를 다듬는다

- 상태: 제안
- 날짜: 2026-11-12
- 변경 작업자: 최혜지 (marong9087)
- 관련 PR: #78 (먼저 올린 #77은 이 PR로 합치며 닫음)

## 작업 내용
- `apps/app/src/app/index.tsx`
  - "사고 현장 모드" 버튼을 처음부터 그리지 않는다. 화면이 열린 뒤 3초가 지나도 로그인 서비스(Clerk)가 로드되지 않았을 때만 "연결이 늦어지고 있어요" 안내와 함께 보인다. 버튼은 기존 `emergency`(빨강) 모양에 경고 아이콘을 붙였다.
  - 절대 좌표 배치를 세로 Flexbox로 바꿨다. 로고 그룹 위·아래 빈 공간을 71:29로 나누고, 위·아래 안전 영역(Safe Area)을 반영한다. 빈 공간은 최소 24px이라 작은 화면에서도 로고와 버튼이 겹치지 않는다.
  - 로딩 표시와 하단 버튼 자리는 내용이 없어도 높이를 잡아 두어, 나타나고 사라져도 로고가 움직이지 않는다.
  - "불러오는 중..." 위에 민트 로딩 막대(120×4px)를 넣었다. 진행률을 알 수 없어 막대가 왼쪽에서 오른쪽으로 계속 지나간다. 문구 색은 회색에서 연한 파랑(`brand400`)으로 바꿨다.
- `apps/app/src/components/ui/Splash.tsx`
  - 진입 모션(1.4초)이 끝난 뒤 완성된 로고를 0.8초 더 보여 준다(1.4초 → 2.2초).
  - 심벌과 AIGO 글씨를 한 묶음(로고 그룹)으로 그리고, 세로 위치는 `index.tsx`가 정한다.
  - 심벌 PNG의 투명 여백(위 약 53px, 아래 약 52px)을 음수 margin으로 상쇄해 보이는 모양 기준으로 배치한다. 보이는 모양이 왼쪽으로 치우친 만큼(약 2.6px) 오른쪽으로 옮겨 글씨와 가로 중심을 맞췄다.
  - 보이는 심벌과 글씨 사이를 51.5px에서 28px로 줄였다. 심벌 크기(273px)와 글씨 크기(200×60px), 모양과 색은 그대로다.
- `apps/app/src/theme.ts`: 로고 민트 `mint: '#3FCF8E'`를 추가했다. 어두운 바탕 위 포인트로만 쓴다.
- `apps/app/src/components/ui/splash.test.tsx`: 바뀐 시간(2.2초), 버튼·지연 안내 조건(로드되면 없음, 로딩 중에는 3초 뒤에만 보임), 로딩 막대에 맞게 테스트를 고쳤다.

## 변경 사유
요청: 최혜지 (marong9087).
- 현장 모드 버튼: 로그인할 때 시작 화면에 버튼이 굳이 없어도 되는데 계속 떠 있어 거슬리고 깔끔하지 않다. 로딩이 늦을 때만 나타나게 하고, 로딩 화면은 0.8초 정도 늘리며, 3~5초가 넘어가면 버튼이 나타나게 해 달라는 요청.
- 배치: 상단 빈 공간이 넓고 로고가 아래로 치우쳐 보여, 브랜드 디자인을 유지하면서 화면 균형을 맞추려고.
- 버튼을 완전히 지우지 않은 이유: 인터넷이 안 되면 Clerk가 끝까지 로드되지 않아 앱이 시작 화면에 머문다. 이때 이 버튼이 사고 현장 모드로 가는 유일한 길이다(ADR 0025).
- 요청 범위(3~5초) 중 3초를 고른 이유: 사고 현장에서는 빨리 들어가는 것이 중요하다. 시작 화면은 2.2초에 끝나므로 정상 로딩이면 3초 전에 다음 화면으로 넘어가 버튼을 보지 않는다. 시간은 `index.tsx`의 `SCENE_BUTTON_DELAY` 한 곳에서 바꾼다.

## 영향
- 390×844 기준 위치: 보이는 심벌 윗변이 338px에서 280px로 약 58px 올라갔다. 글씨 476~536px, 로딩 막대 576px, 문구 594px, 버튼 760~812px(아래 여백 32px).
- 360×640, 412×915에서도 같은 비율로 배치되며 로고와 버튼이 겹치지 않는다. 높이 약 560px보다 낮은 화면은 확인하지 않았다.
- 버튼 높이는 공통 `Button` 컴포넌트의 52px를 그대로 썼다(시안은 54px).
- 민트는 이 화면의 로딩 막대에만 썼다. 다른 화면의 색은 바꾸지 않았다. 앱 전체에 민트를 어떻게 쓸지는 팀 합의 후 따로 정한다.
- 로그인 화면(`sign-in.tsx`)과 공유 화면(`share.tsx`)의 사고 현장 모드 버튼은 바꾸지 않았다.
- 확인: 앱 타입 검사와 테스트 통과. 로컬 웹 미리보기에서 390×844, 360×640, 412×915 배치와 3초 지연 동작을 확인했다. 갤럭시 실기기에서는 확인하지 않았다.
