# 0038. 계정 화면을 남색 머리글·민트로 맞추고, 하단 메뉴와 겹치는 줄을 빼고, 탈퇴를 로그아웃 아래 작은 글씨로 내린다

- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #98

## 작업 내용
계정 화면(`app/(tabs)/account.tsx`)의 모양과 순서를 바꿨다. 로그아웃·탈퇴 동작과 확인 창은 그대로다.

- 머리글: 회색 바탕의 "계정" 제목(`PageTitle`) → 남색 머리글(`ReportHeader`), 상태바 자리도 남색.
- 프로필: 파랑(`brand`) 네모에 남색 글자 → 남색(`ink`) 네모에 민트 글자. 가입일 글씨 12 → 13px.
- 메뉴 줄(`ui/Section`의 `MenuRow`, `IconTile`): 아이콘 바탕 연파랑 → 연한 민트(`mintSoft`), 아이콘 파랑 → 진한 민트(`mintDeep`). 제목 14 → 15px, 설명 12 → 13px. 위험·급한 줄의 빨강은 그대로다. `MenuRow`는 이 화면에서만 쓴다.
- 내 서비스: 하단 메뉴에 이미 있는 "내 분석"과 "사고 현장 모드" 줄을 빼고, 하단 메뉴에 없는 "상품 보기"만 남겼다.
- 순서: 프로필 → 내 서비스(상품 보기) → 로그아웃 → 맨 아래 작은 빨간 밑줄 "탈퇴하기"와 "계정과 분석 기록을 모두 지워요" → 앱 버전. "계정 관리" 묶음은 없앴다.

## 변경 사유
계정 화면 UX/UI 수정 - 최혜지

다른 화면을 남색·민트로 맞춘 뒤 계정 화면만 회색 제목과 파랑이 남았다. 되돌릴 수 없는 탈퇴가 자주 쓰는 로그아웃보다 위에 큰 줄로 있어 먼저 눈에 띄고 잘못 누르기 쉬웠다. "내 분석"과 "사고 현장 모드"는 하단 메뉴와 같은 곳으로 가는 줄이라 겹쳤다(그중 사고 현장 모드 설명은 바뀐 기능 "체크리스트"를 가리키고 있었다). 내 서비스를 그대로 두는 안도 찍어 비교한 뒤, 겹치지 않는 상품 보기만 남기는 안을 골랐다(최혜지 선택).

## 영향
- 서버 API는 바뀌지 않았다. 탈퇴는 지금처럼 확인 창을 거친다. 계정 화면에서 내 분석·사고 현장 모드로 가는 줄은 없어졌고, 하단 메뉴로 간다.
- 하단 메뉴에서 선택된 탭의 동그라미는 아직 파랑이다(모든 화면 공통, 다음에 정한다).
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(119개 통과). 웹 빌드로 전·후와 내 서비스를 그대로 둔 안을 찍어 비교했다. 실제 안드로이드 기기에서는 아직 보지 않았다.
