# 0023. 팀원은 AI 에이전트와 함께 고치는 것을 기본으로 한다

- 상태: 채택 (CONTRIBUTING의 GitHub 웹 편집 중심 안내를 대체)
- 날짜: 2026-11-10
- 변경 작업자: 조준형 (jcmaker), Claude Code 사용
- 관련 PR: 참여 안내 개정 PR

## 작업 내용
- `CONTRIBUTING.md`를 AI 에이전트(Claude Code, Codex, Cursor) 사용을 기본으로 다시 썼습니다.
  - 처음 준비: 초대 수락, 에이전트 설치, 에이전트에게 저장소 받기와 `gh auth login` 안내 맡기기
  - 고치는 순서 7단계: 무엇을·왜 말하기 → 에이전트 질문에 답하기 → 에이전트가 브랜치·수정·ADR·검사·PR → 화면 직접 확인 → PR 페이지에서 CI 확인 → 리뷰 대응
  - 에이전트에게 쓸 만한 말, 에이전트 채팅에 비밀값을 붙이지 않기, 머지를 시키지 않기
  - GitHub 웹 편집은 "작은 문구 수정" 대안으로 남김
- `AGENTS.md`에 브랜치 만들기, `gh pr create --base dev`, 검사 결과 전달, 비개발자에게 쉬운 설명과 화면 확인, 부탁하지 않은 파일 수정 금지, `--admin`·강제 푸시 금지를 더했습니다.

## 변경 사유
팀원들은 GitHub 웹에서 직접 고치기보다 Claude Code, Codex, Cursor 같은 에이전트와 작업할 가능성이 훨씬 큽니다(조준형). 안내가 실제 작업 방식과 맞아야 팀원이 따라 할 수 있습니다.

## 영향
- 팀원은 코드 대신 "무엇을, 왜"를 말하고 결과를 확인하는 역할입니다.
- 에이전트가 쓴 PR 내용과 검사 결과는 사람이 PR 페이지에서 직접 확인합니다.
- 에이전트가 규칙을 어겨도 PR 가드레일, 비밀값 검사, 브랜치 보호, CODEOWNERS 승인이 막습니다.
