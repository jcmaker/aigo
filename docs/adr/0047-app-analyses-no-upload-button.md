# 0047. 내 분석 목록 아래 "영상 올리기" 버튼을 뺀다

- 상태: 제안
- 날짜: 2026-11-23
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #99

## 작업 내용
- `app/(tabs)/analyses.tsx`: 분석이 1건 이상일 때 목록 맨 아래에 있던 "영상 올리기" 버튼을 없앴다(ADR 0032에서 남겨 둔 것).
- 분석이 0건일 때 빈 화면의 "영상 올리기" 버튼은 그대로 둔다. 그때는 이 화면에서 할 수 있는 다음 동작이 그것뿐이다.

## 변경 사유
같은 화면(영상 분석하기)으로 가는 길이 하단 메뉴 "분석하기"와 홈의 남색 카드(누르면 갤러리가 바로 열림, ADR 0039)로 이미 있다. 목록이 길어지면 버튼이 맨 아래로 밀려 끝까지 내려야 보인다. 내 분석은 기록을 보고 정리(ADR 0043)하는 화면이다(최혜지 요청).

## 영향
- 하단 메뉴가 아이콘만 있어 카메라 아이콘이 영상 올리기라는 것을 처음엔 모를 수 있다. 홈 카드가 크게 안내한다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(129개 통과). 웹 빌드로 내 분석 목록을 찍었다.
