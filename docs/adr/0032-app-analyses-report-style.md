# 0032. 내 분석 화면을 분석 리포트와 같은 남색 머리글·흰 탭·결과 중심 카드로 맞춘다

- 상태: 제안
- 날짜: 2026-11-14
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #번호

## 작업 내용
내 분석창 UX/UI 수정: 분석 리포트(ADR 0027)와 같은 느낌으로 맞춘다.

- 머리글(`app/(tabs)/analyses.tsx`): 회색 바탕의 "내 분석" 제목 → 리포트와 같은 남색 머리글(`ReportHeader`). 제목은 가운데, 아래 줄에 "분석 5건 · 진행 중 1건"(0건이면 "영상을 올리면 과실 범위를 알려드려요"). 예전 오른쪽 위 영상 올리기 버튼은 뺐다: 하단 메뉴 "분석하기"와 화면 안 버튼(빈 화면의 남색 카드, 목록 아래)과 같은 곳으로 가서 겹치고, 남색 머리글 안 작은 아이콘은 무슨 버튼인지 알기 어렵다(최혜지 요청). 탭 화면이라 뒤로 버튼 자리는 같은 너비의 빈 칸으로 둔다(`ReportHeader`의 `onBack`을 선택으로 바꿈).
- 필터: 회색 캡슐(`SegmentedControl`) → 리포트와 같은 흰 탭 + 민트 밑줄(`ReportTabs`). "분석 목록 N건" 줄은 머리글 아래 줄과 겹쳐 없앴다.
- 목록 카드(`components/AnalysisRow.tsx`, 홈의 "최근 분석"도 같이 쓴다)
  - 회색 영상 네모 → 상태 아이콘(완료: 민트 문서, 분석 중: 노랑 영상, 실패: 빨강 경고, 그 밖: 회색).
  - 내 과실 범위를 오른쪽에 크게(18px, 진한 민트 `mintDeep`). 360px 미만 화면에서는 상태 줄 아래에 "내 과실 20~40%"로 둔다.
  - 사용자에게 의미 없는 `#번호`를 뺐다. 분석 중이면 제목을 "영상을 분석하고 있어요", 업로드가 안 끝났으면 "영상 업로드가 끝나지 않았어요"로 보인다.
  - 줄마다 있던 휴지통을 빼고, 길게 누르면 삭제 확인 창이 뜨게 했다(리포트 화면 ⋯ 메뉴에도 삭제가 있다).
  - "완료" 칩을 파랑에서 민트(`mintSoft` 바탕, `mintDeep` 글씨, 대비 4.85:1)로 바꿨다(`StatusChip`의 good).

## 변경 사유
내 분석창 UX/UI 수정 - 최혜지

분석 리포트를 남색 머리글·흰 탭·민트로 바꾼 뒤, 그 리포트로 들어가는 목록 화면은 예전 회색·파랑이라 같은 앱처럼 보이지 않았다. 목록에서 가장 궁금한 값(내 과실 범위)이 작은 회색 글씨였고, 줄마다 휴지통이 있어 열려다 잘못 누르기 쉬웠다.

## 영향
- 분석 목록의 삭제는 휴지통 대신 길게 누르기로 바뀌었다(삭제 확인 창은 그대로). 화면 읽기 기능에는 "길게 누르면 삭제할 수 있어요"라고 알린다.
- "완료" 칩 색은 `StatusChip`의 good을 쓰는 모든 곳에서 민트가 된다(현재는 분석 목록과 홈 최근 분석).
- 기능과 서버 API는 바뀌지 않았다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(108개 통과, 목록 카드 테스트 갱신: 큰 과실 범위, #번호 없음, 길게 눌러 삭제). 웹 빌드로 전체·진행 중·빈 화면·320px를 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
