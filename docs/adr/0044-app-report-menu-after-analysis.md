# 0044. 분석 화면의 ⋯는 분석이 끝난 뒤에만 보인다

- 상태: 제안
- 날짜: 2026-11-23
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: (올린 뒤 적음)

## 작업 내용
- `app/analyses/[id].tsx`: 분석이 대기·분석 중일 때는 머리글 오른쪽 위 ⋯(더 보기)를 숨긴다. 완료·실패가 되면 나타난다(PDF로 보내기, 영상 다시 올리기, 분석 삭제).

## 변경 사유
분석 중에는 PDF 보내기와 다시 올리기가 이미 숨겨져 ⋯ 메뉴에 "분석 삭제" 한 줄만 남았다. 기다리는 화면에서 누를 이유가 없고 잘못 눌러 지울 위험만 있다(최혜지 요청). 분석 중인 것을 지웠을 때 서버가 분석을 바로 멈추는지도 확인 전이다.

## 영향
- 분석 중에 지우려면 끝난 뒤 지우거나 내 분석 목록에서 길게 눌러 지운다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`. 웹 빌드로 분석 중(⋯ 없음)과 완료(⋯ 있음)를 찍었다.
