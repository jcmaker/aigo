# 0024. 문서만 바뀐 PR은 코드 검사를 건너뛴다

- 상태: 채택
- 날짜: 2026-11-10
- 변경 작업자: 조준형 (jcmaker), Claude Code 사용
- 관련 PR: 문서 CI 생략 PR

## 작업 내용
- CI(`.github/workflows/ci.yml`)에 "바뀐 파일 분류" 작업을 두었습니다. 바뀐 파일이 모두 `docs/` 아래이거나 `.md`, `.txt` 파일이면 API 테스트, 웹 테스트·빌드, 앱 검사를 건너뜁니다.
- 하나라도 다른 파일(코드, 설정, `.github/` 워크플로, 이미지 등)이 섞이면 세 검사를 모두 돌립니다. 바뀐 파일 목록을 구하지 못해도 검사합니다.
- 워크플로는 그대로 시작하고 작업만 건너뜁니다. 건너뛴 작업은 브랜치 보호에서 통과로 칩니다. 워크플로 자체를 안 돌리면 필수 검사가 "대기 중"으로 남아 머지가 막히기 때문입니다.
- PR 가드레일과 비밀값 검사는 문서 변경에도 그대로 돕니다.

## 변경 사유
팀원의 수정은 문구와 문서가 많습니다. 문서만 바꿨는데 서버 테스트와 빌드를 몇 분씩 기다릴 필요가 없습니다(조준형 요청).

## 영향
- 문서 PR은 검사 대기 시간이 거의 없습니다.
- 문서에도 ADR 추가와 비밀값 검사는 그대로 적용됩니다(ADR 0001, 0005).
- 문서만 바뀐 `main` 머지는 배포도 하지 않습니다(ADR 0022).
