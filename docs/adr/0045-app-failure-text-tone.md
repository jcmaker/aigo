# 0045. 분석 실패 안내 문구를 "~어요"로 맞춘다

- 상태: 제안
- 날짜: 2026-11-23
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #99

## 작업 내용
- `lib/analysis.ts`의 실패 제목·도움말(`FAILURES`)과 기본 제목, `components/analysis.tsx`의 실패·업로드 중단 제목을 "~습니다" → "~어요"로 바꿨다. 예: "분석을 끝내지 못했습니다" → "분석을 끝내지 못했어요", "영상이 너무 깁니다" → "영상이 너무 길어요". "레포트" → "리포트"로 표기를 맞췄다. 뜻은 그대로다.
- 리포트 본문, 로그인 오류 문구는 이번에 바꾸지 않았다.

## 변경 사유
내 분석 목록에서 실패한 분석 제목만 "~습니다"라 다른 줄("영상을 분석하고 있어요")과 말투가 달랐다(최혜지 확인). 같은 문구를 쓰는 분석 화면과 알림도 함께 맞췄다.

## 영향
- 화면 문구만 바뀐다. 테스트의 기대 문구 2곳을 같이 고쳤다(`report.test.tsx`, `notices.test.ts`).
