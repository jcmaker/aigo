# 0016. 분석 이용 한도

- 상태: 채택
- 날짜: 2026-11-05
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 2026-11-05 5장, PR #5

## 작업 내용
- 형식: mp4, mov, webm, avi
- 크기 200MB, 길이 2분
- 사용자당 하루 5건, 서비스 전체 하루 100건. 모두 환경변수로 바꿀 수 있습니다.
- 사용자 한도는 실패한 분석을 세지 않고, 전체 한도는 실패도 셉니다.

## 변경 사유
- 계정을 새로 만들어도 OpenAI 비용이 일정 수준을 넘지 않게 합니다.
- 실패도 OpenAI 비용이 들어서 전체 한도에는 셉니다. 사용자에게는 실패를 탓하지 않습니다.
