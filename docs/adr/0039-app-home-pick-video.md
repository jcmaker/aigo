# 0039. 홈의 "갤러리에서 영상 고르기"는 갤러리를 바로 연다

- 상태: 제안
- 날짜: 2026-11-22
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: (올린 뒤 채움)

## 작업 내용
- 홈의 "사고 영상, 바로 분석해요" 카드(`app/(tabs)/home.tsx`)를 누르면, 버튼이든 카드의 빈 곳(제목, 카메라 그림)이든 갤러리를 바로 연다. 전에는 영상 분석하기 화면으로 이동만 했다.
- 영상을 고르면 그 영상이 선택된 채로 영상 분석하기 화면으로 간다. 사용자는 동의하고 올리기만 하면 된다. 갤러리에서 취소하면 홈에 그대로 남는다.
- 넘기는 값은 `lib/upload.ts`의 `pickedParams`가 만든다(주소, 이름, 크기, 형식, 길이(초), `from=home`). 길이를 넘겨서 영상 분석하기 화면이 구간 막대와 2분 초과 안내를 바로 보인다.
- 영상 분석하기 화면(`app/(tabs)/upload.tsx`)은 공유 메뉴로 받은 영상과 같은 길로 받는다. `from=home`이면 직접 고른 영상으로 다룬다(공유로 받은 영상과 달리 동의를 다시 끄지 않는다. 처음 들어올 때는 어차피 꺼져 있다).

## 변경 사유
홈 버튼 이름은 "갤러리에서 영상 고르기"인데 누르면 영상 분석하기 화면으로 넘어가기만 해서, 거기서 같은 버튼을 한 번 더 눌러야 했다(최혜지 지적). 카드의 어디를 눌러도 결과가 같아야 헷갈리지 않아서 카드 전체가 갤러리를 열게 했다.

## 영향
- 서버 API와 올리기 순서는 바뀌지 않았다. 다른 화면의 "영상 올리기" 버튼(내 분석 빈 화면 등)은 지금처럼 영상 분석하기 화면으로 이동한다.
- 갤러리 선택기의 한계(사진 앱에 등록된 영상만 보임)는 그대로다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(122개 통과, `pickedParams` 테스트 추가). 실제 안드로이드 기기에서는 아직 보지 않았다.
