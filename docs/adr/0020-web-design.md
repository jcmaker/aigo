# 0020. 웹 디자인: rizz-shorts 토큰과 ArtCraft 구성

- 상태: 채택
- 날짜: 2026-11-05
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 2026-11-05 7~8장, PR #8, #16

## 작업 내용
- `rizz-shorts`의 토큰 체계(종이색 바탕, 1px 선 격자, 각진 모서리, Pretendard와 Geist Mono, 밝은/어두운 테마)를 씁니다.
- getartcraft.com/apps의 구성(`01/` 번호 섹션, 번호 붙은 카드, 원칙 목록, CTA 띠, 4열 푸터)을 참고합니다. 로고, 이미지, 문구는 쓰지 않습니다.
- 강조색은 파랑(`#2d81ff`, 글자 `#1659c4`)이고 빨강은 심각도와 오류에만 씁니다.
- 랜딩 메시지는 "사고를 판정하는 AI가 아니라 사고 대응력을 높이는 AI"이고, 푸터에 캡스톤 가상 서비스임을 표시합니다.

## 변경 사유
- 레퍼런스 두 곳은 조준형이 정했습니다. 두 곳이 같은 종이색 바탕과 Geist Mono를 써서 잘 어울립니다.
- 빨강을 강조색으로 쓰면 사고 화면에서 위험 표시의 의미가 흐려집니다.

## 영향
- 지어낸 후기, 고객 수, 정확도 수치는 랜딩에 넣지 않습니다.
- 앱은 다른 디자인(ADR 0018)을 씁니다.
