# 0010. 결제는 토스 테스트 키만, 금액은 서버가 계산

- 상태: 채택
- 날짜: 2026-11-05
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 2026-11-05 6장, PR #4, #9

## 작업 내용
- 상품은 표준형과 상위형 2종이고 시드 데이터로 넣습니다. 장바구니 없이 상품 상세에서 바로 삽니다.
- `POST /orders`가 DB 가격으로 금액을 계산합니다. 결제 승인 때 주문 금액과 토스가 돌려준 금액이 다르면 거절합니다.
- 토스 승인은 `Idempotency-Key`를 쓰고, 이미 `paid`인 주문은 그대로 성공을 돌려줍니다.
- 토스 공식 문서용 테스트 키 세트만 씁니다. 서버는 `test_`로 시작하지 않는 키를 받으면 시작하지 않습니다.
- 체크아웃과 주문 화면에 "테스트 결제입니다. 실제로 청구되지 않습니다"를 표시합니다.
- 주문에 상품명과 단가를 복사해 둡니다. 탈퇴하면 주문은 사용자 연결만 끊고 보관합니다.

## 변경 사유
- 캡스톤 가상 서비스라 실제 결제는 하지 않습니다(조준형 결정).
- 클라이언트가 보낸 금액을 믿으면 금액 위조로 결제할 수 있습니다.
- 상품을 고쳐도 지난 주문이 바뀌면 안 됩니다.

## 영향
- 실제 결제, 환불, 배송, 재고, 관리자 화면은 만들지 않습니다.
- 앱은 상품 구매를 새로 만들지 않고 웹 페이지를 엽니다(ADR 0017).
