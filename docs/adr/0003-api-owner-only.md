# 0003. 백엔드(apps/api)는 관리자만 고친다

- 상태: 채택
- 날짜: 2026-11-09
- 변경 작업자: 조준형 (jcmaker)
- 관련 PR: 가드레일 PR

## 작업 내용
- 관리자가 아닌 사람의 PR이 `apps/api/` 아래 파일을 바꾸면 CI의 "PR 가드레일" 검사가 실패합니다.
- `AGENTS.md`와 `CLAUDE.md`에 AI 도구가 `apps/api/`를 고치지 않도록 적습니다.
- 팀원은 웹(`apps/web`), 앱(`apps/app`), 문서(`docs`, `README.md`)를 고칠 수 있습니다.

## 변경 사유
`apps/api`에는 인증, 결제, 영상 분석, 데이터베이스 마이그레이션이 있습니다. 잘못 고치면 운영 데이터와 결제가 깨지고, 되돌리기 어렵습니다. 조준형이 백엔드 작업은 막도록 요청했습니다.

## 영향
- API를 바꿔야 하는 일이 생기면 팀원은 이슈나 PR 댓글로 조준형에게 요청합니다.
- 관리자는 이 검사에서 제외됩니다.
