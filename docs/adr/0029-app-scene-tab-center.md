# 0029. 사고 현장 모드 탭을 가운데로 옮기고, 홈 카드 이름을 "사고 현장 모드"로 맞춘다

- 상태: 제안
- 날짜: 2026-11-14
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #번호

## 작업 내용
사고 현장 모드 탭을 중앙으로 옮기고, 홈의 "사고 났어요" 글자를 "사고 현장 모드"로 변경.

- 하단 탭 순서: 홈 · 내 분석 · 분석하기 · 현장 모드 · 계정 → 홈 · 내 분석 · **사고 현장 모드** · 분석하기 · 계정 (`components/ui/FloatingTabBar.tsx`의 `TAB_ITEMS`).
- 탭의 접근성 이름 "현장 모드"를 "사고 현장 모드"로 바꿨다.
- 홈 빨간 카드 제목 "사고 났어요"를 "사고 현장 모드"로 바꿨다(`app/(tabs)/home.tsx`). 설명 "신고 · 현장 기록"과 누르면 가는 화면(`/emergency`)은 그대로다.

## 변경 사유
홈의 "사고 났어요" 카드와 하단 4번째 "현장 모드" 탭, 시작 화면의 "사고 현장 모드" 버튼이 모두 같은 화면(`SceneBody`)인데 이름이 달라 다른 기능처럼 헷갈렸다. 사고 대응 앱에서 가장 급한 기능이라 하단 메뉴 가운데에 두어 바로 누를 수 있게 한다. - 최혜지

## 영향
- 기능과 화면 이동은 바뀌지 않았다. 탭의 경로 이름(`emergency`)도 그대로다.
- ADR 0028(홈 화면) 브랜치 위에서 작업했다. 두 작업이 홈 파일의 같은 부분을 고쳐서, 0028 PR이 먼저 머지되어야 이 PR에 이 변경만 남는다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(108개 통과, 탭 순서 테스트 갱신). 웹 빌드로 홈과 하단 탭 전·후를 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
