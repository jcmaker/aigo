# 0036. 영상 분석하기 화면을 남색 머리글·번호 단계·민트로 맞춘다

- 상태: 제안
- 날짜: 2026-11-22
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: (올린 뒤 채움)

## 작업 내용
영상 분석하기 화면(`app/(tabs)/upload.tsx`)의 모양을 바꿨다. 올리기 순서, 구간 자르기, 하루 한도 처리 같은 동작은 바꾸지 않았다.

- 머리글: 회색 바탕의 "영상 분석하기" 제목 → 리포트·내 분석과 같은 남색 머리글(`ReportHeader`). 아래 줄에 "과실 비율과 근거 장면을 알려드려요"(홈 분석 카드 문구). 상태바 자리도 남색이다.
- 번호 단계: 화면을 ① 영상 고르기 → ② 확인하고 동의하기 → ③ 올리고 분석 시작으로 나눴다(`StepTitle`). 번호는 연한 민트 동그라미이고, 영상을 고르면 ①, 동의를 켜면 ②가 진한 민트 체크로 바뀐다.
- 영상 고르기 카드: 파랑(`brand`) → 남색(`ink`) 바탕, 민트 카메라 아이콘, 흰 버튼(`onDark`). 홈의 "사고 영상, 바로 분석해요" 카드와 같은 모양이다. 형식 안내를 카드 안으로 옮기고 "사고 앞뒤가 담긴 영상"을 앞에 붙였다.
- 영상을 고르기 전에는 형식 안내 줄 대신 접히는 "블랙박스 영상, 어떻게 찾나요?"를 보인다. 내 분석 빈 화면(ADR 0031)에 있던 것을 `components/FindVideoTips.tsx`로 꺼내 두 화면이 함께 쓴다(문구는 그대로).
- 동의 스위치(`ConsentSwitch`)의 켜진 색: 파랑 → 진한 민트(`mintDeep`). 이 스위치는 이 화면에서만 쓴다.
- 구간 막대: 파랑 테두리·연파랑 → 진한 민트 테두리·연한 민트.
- 올리는 중: "올리는 중 n%" 글자 아래에 진한 민트 진행 막대를 더했다.
- 동의 문구(ADR 0015)는 바꾸지 않았다.

## 변경 사유
영상 분석하기 UX/UI 수정 - 최혜지

리포트·홈·내 분석을 남색·민트로 바꾼 뒤 이 화면은 파랑 카드와 회색 제목이 남아 다른 앱처럼 보였다. 영상 고르기, 형식 안내, 동의, 올리기가 그냥 세로로 늘어서 있어 지금 몇 번째 단계인지 알기 어려웠다. 에뮬레이터에서 영상을 찾지 못해 막힌 일이 있어, 블랙박스 영상 찾는 법을 이 화면에서도 볼 수 있게 했다.

## 영향
- 기능, 화면 이동, 서버 API는 바뀌지 않았다.
- 갤러리 선택기는 사진 앱에 등록된 영상만 보여 주는 문제(다운로드 폴더의 영상을 못 고름)는 그대로다. "파일에서 고르기"는 새 네이티브 모듈과 새 APK가 필요해 이번에 넣지 않았다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(119개 통과). 웹 빌드로 영상을 고르기 전 화면(기본, 안내 펼침·동의 켬)을 찍어 전·후를 비교했다. 영상을 고른 뒤 화면(구간 막대·진행 막대)과 실제 안드로이드 기기는 아직 보지 않았다.
