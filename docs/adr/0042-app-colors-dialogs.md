# 0042. 남은 파랑을 남색·민트로 바꾸고, 되돌릴 수 없는 확인 창을 앱 모양으로 통일한다

## 작업 내용
### 색 (ADR 0026~0041에서 정한 남색·민트 기준을 남은 곳에 적용)
- 기본 버튼(`ui/Button` primary): 파랑(`brand`) → 남색(`ink`). 알릴 사람 "저장", 로그인, "올리고 분석 시작" 등.
- 하단 메뉴(`ui/FloatingTabBar`): 선택된 탭 동그라미 파랑 → 민트(`mint`, 남색 바 위), 선택된 아이콘 흰색 → 남색.
- 홈 "전체 보기" 같은 묶음 제목 링크(`ui/Section`의 `SectionTitle`): 파랑 → 진한 민트.
- 알림 화면(`app/notifications.tsx`): 회색 바탕 제목(`TopBar`) → 남색 머리글(`ReportHeader`, 상태바 자리도 남색), 완료 아이콘과 안 읽음 점 파랑 → 민트, 제목 14 → 15px.
- 알릴 사람(`components/ContactsCard.tsx`): 이름 동그라미 연파랑 → 연한 민트, 전화 버튼 파랑 → 남색.
- 로그인·회원가입 링크, 인증번호 입력칸 테두리, 현장 사진 선택 테두리, 빈 화면 아이콘(`ui/EmptyState`), 시각 칩 기본값(`ui/Chips`), 게이지(`ui/SegmentGauge`): 파랑 → 진한 민트·연한 민트.
- 남색 위 흐린 글씨(`brand400`, 머리글 아래 줄·시작 화면 로딩 글씨 등)는 남색 바탕용 글자색이라 그대로 둔다.

### 확인 창
- 앱 모양 확인 창 `ui/ConfirmDialog`(`useConfirm`)을 만들었다. 제목, 설명, 실행 버튼(되돌릴 수 없으면 빨강, 아니면 남색), 취소 버튼, 바깥을 누르면 닫힘. 112·119 확인 창(ADR 0035)도 이것으로 바꿨다(모양·문구 같음).
- 휴대폰 기본 회색 창(`Alert.alert`)을 쓰던 되돌릴 수 없는 확인을 모두 이 창으로 바꿨다: 분석 삭제(리포트 ⋯ 메뉴, 내 분석 길게 누르기), 탈퇴, 현장 사진 삭제, 알릴 사람 삭제.
- 문구를 "~어요"로 맞췄다: "분석을 지울까요? / 이 분석과 영상 파일을 지워요. 되돌릴 수 없어요.", "탈퇴할까요? / 계정과 분석 기록이 모두 지워져요. 되돌릴 수 없어요.", "사진을 지울까요?", "이 연락처를 지울까요?"(이름·관계·번호를 설명에 보임, "을(를)" 표기를 없앰).
- 남은 기본 창(오류 안내: 전화·앱을 열 수 없음, 카메라 권한, 공유·삭제 실패, 분석을 찾을 수 없음, 보험사 번호 없음)은 그대로 두고 문구만 "~어요"로 바꿨다.

### 사진 저장 알림
- 사고 현장 모드에서 사진을 찍으면 뜨던 "사진을 저장했습니다" 기본 창(확인을 눌러야 닫힘) → 화면 아래(112·119 버튼 위)에 약 2초 떴다 사라지는 남색 알림 "사진을 저장했어요"(`SceneBody`).

## 변경 사유
화면별 개편 뒤에도 기본 버튼, 하단 메뉴, 알림 화면, 알릴 사람 등 여러 화면에 공통으로 쓰는 부품에 파랑이 남아 있었다. 되돌릴 수 없는 삭제·탈퇴는 휴대폰 기본 회색 창이라 앱의 112·119 확인 창과 모양이 달랐고 말투도 "~습니다"였다. 사고 현장에서 사진을 찍을 때마다 확인을 눌러야 하는 것도 번거로웠다(최혜지 요청: "지금까지 수정하는 방향으로").

## 영향
- 기능, 화면 이동, 서버 API는 바뀌지 않았다. 확인 창은 지금처럼 취소하면 아무 일도 없다.
- 기본 버튼 색이 바뀌어 `primary`를 쓰는 모든 화면이 남색 버튼이 된다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(125개 통과, 확인 창 테스트 추가: 취소하면 실행 안 함, 실행 버튼을 눌러야 실행). 웹 빌드로 홈 하단 메뉴, 알림, 알릴 사람, 탈퇴·분석 삭제 확인 창을 찍었다. 로그인·회원가입 화면, 사진 저장 알림, 실제 안드로이드 기기는 아직 보지 않았다.
