# 0037. 분석 진행 화면의 머리글·색·말투를 앱 기준에 맞추고, "닫아도 된다" 안내를 위로 올린다

- 상태: 제안
- 날짜: 2026-11-22
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: (올린 뒤 채움)

## 작업 내용
분석 진행 화면(ADR 0033, 조준형)의 구조와 움직임(단계·경과 시간·회전 링·바뀌는 안내·진행 막대)은 그대로 두고 겉모습만 바꿨다.

- 머리글(`app/analyses/[id].tsx`): 분석 중(queued, processing)이거나 아직 불러오기 전이면 "분석 #24" 대신 "영상을 분석하고 있어요"를 보인다. 내 분석 목록 카드(ADR 0032)와 같은 문구다. 끝난 분석은 지금처럼 사고 제목이다.
- 색: "n/6 단계" 글씨, 진행 막대(`ProgressBar`), 단계 목록(`ui/StepList`)의 완료 체크·회전 링·경과 초·진행 중 안내를 파랑(`brand`) → 진한 민트(`mintDeep`, 바탕은 `mintSoft`)로 바꿨다. `StepList`는 이 화면에서만 쓴다.
- 말투(`lib/analysis.ts`의 `STAGES[].about`): "만듭니다 / 따라갑니다 / 봅니다 / 뽑습니다 / 적습니다 / 맞춰 봅니다" → "~어요"로 바꿔 진행 중 안내("찾고 있어요")와 맞췄다. 내용은 그대로다.
- "화면을 닫아도…" 안내: 맨 아래 회색 `Notice` → 진행 카드 바로 아래 연한 민트 상자(체크 아이콘)로 올리고 "화면을 닫아도 분석은 계속돼요. 끝나면 내 분석에서 볼 수 있어요."로 바꿨다.
- "홈으로 가기" 버튼은 넣지 않았다(A안). 왼쪽 위 뒤로 버튼이 있고, 버튼을 넣으면 진행 단계가 아래로 밀린다.

## 변경 사유
분석 진행 UX/UI 수정 - 최혜지

리포트·홈·내 분석·사고 현장 모드·영상 분석하기를 남색·민트로 맞춘 뒤 이 화면만 파랑이 남았다. 내 분석 목록에서 뺀 의미 없는 "#번호"가 머리글에 남아 있었고, 단계 설명과 진행 안내의 말투가 섞여 있었다. 기다리는 사용자에게 가장 중요한 "닫아도 된다"는 안내가 맨 아래 작은 회색 글씨라 잘 보이지 않았다.

## 영향
- 기능, 화면 이동, 서버 API, 진행 계산과 움직임은 바뀌지 않았다.
- 예상 시간과 "끝나면 알림을 보내요"는 넣지 않았다(잰 값이 없고, 알림 실제 수신이 아직 확인되지 않음).
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(119개 통과). 웹 빌드로 2/6 단계 진행 화면 전·후와 "홈으로 가기" 버튼 있는 안(B)을 찍어 비교했다. 실제 안드로이드 기기에서는 아직 보지 않았다.
