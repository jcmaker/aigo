# 0040. 사고 현장 모드 결과 화면은 "다시 답하기" 대신 "이전 질문" 뒤로 버튼을 둔다

- 상태: 제안
- 날짜: 2026-11-22
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #98

## 작업 내용
- 사고 현장 모드의 결과 화면(지금 할 일·사고 뒤 할 일, `components/SceneGuide.tsx`) 요약 카드 오른쪽 아래의 "다시 답하기"(모든 답을 지우고 처음부터)를 없앴다.
- 그 카드 왼쪽 위에 질문 카드와 같은 모양의 뒤로 버튼 "‹ 이전 질문"을 두었다. 누르면 마지막 질문으로 돌아가고, 앞의 답은 그대로 남는다. 질문 카드의 뒤로 버튼과 같은 동작(`back`)이다. 여러 번 누르면 처음 질문까지 돌아갈 수 있다.
- 연기·불 "네"로 끝나는 대피 안내 화면도 같은 버튼을 쓴다.

## 변경 사유
"다시 답하기"는 오른쪽 아래 작은 민트 글씨라 뒤로 가는 버튼으로 보이지 않았고, 누르면 답이 모두 지워져 한 가지 답만 고치고 싶을 때도 처음부터 다시 답해야 했다. 질문 화면처럼 왼쪽 위 뒤로 버튼이 있어야 직관적이다(최혜지 요청).

## 영향
- 질문 순서와 안내 문구는 바뀌지 않았다. 체크해 둔 "지금 할 일" 완료 표시는 뒤로 갔다 와도 같은 항목이면 남는다.
- 한 번에 처음부터 다시 시작하는 버튼은 없어졌다(뒤로를 여러 번 누르거나 화면을 다시 열면 된다).
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(123개 통과, "이전 질문을 누르면 마지막 질문으로 돌아가고 앞의 답은 남는다" 테스트 추가). 웹 빌드로 결과 화면 전·후를 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
