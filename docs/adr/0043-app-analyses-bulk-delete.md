# 0043. 내 분석에서 여러 개를 골라 지우거나 탭의 분석을 모두 지우고, "진행 중" 탭을 뺀다

- 상태: 제안
- 날짜: 2026-11-23
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: (올린 뒤 적음)

## 작업 내용
- 내 분석 남색 머리글 오른쪽 위에 ⋯(더 보기)를 둔다(분석이 1건 이상일 때만). 리포트 화면 ⋯와 같은 메뉴 상자(`ReportMenu`)에 "선택해서 지우기", "모두 지우기"(완료 탭에서는 "완료된 분석 모두 지우기")가 있다.
- 선택해서 지우기(`app/(tabs)/analyses.tsx`, `components/AnalysisRow.tsx`):
  - 머리글이 "n개 선택됨 / 지울 분석을 눌러 고르세요"로 바뀌고, 줄마다 상태 아이콘 자리에 체크 동그라미가 나온다. 고른 줄은 연한 민트 바탕 + 진한 민트 테두리.
  - 대기·분석 중인 분석은 흐리게 보이고 고를 수 없다(`lib/ui-logic.ts`의 `deletable`). 서버에서 돌고 있는 분석을 지웠을 때 어떻게 되는지 확인 전이라 막는다.
  - 화면 아래(하단 메뉴 바로 위)에 "취소"와 빨간 "n개 지우기"를 고정한다. 누르면 앱 모양 확인 창(ADR 0042) "분석 n건을 지울까요?"를 거친다.
- 모두 지우기: 지금 탭에 보이는 분석 중 지울 수 있는 것(분석 중 제외)을 모두 지운다. 확인 창에 건수를 보인다("분석 5건을 모두 지울까요?").
- 지우기는 지금 있는 하나 지우기 API(`DELETE /api/v1/analyses/{id}`)를 하나씩 부른다. 이미 지워진 것(404)은 지운 것으로 치고, 실패한 건은 "n건은 지우지 못했어요"로 알린다.
- 길게 눌러 하나 지우기는 그대로 둔다.
- 필터 탭 "진행 중"을 뺀다(전체 · 완료). 분석은 몇 분이면 끝나 이 탭은 거의 늘 비어 있고, 진행 중인 분석은 머리글 아래 줄("진행 중 1건")과 전체 목록 맨 위에서 이미 보인다.
- 밀어서 지우기는 넣지 않았다. 미는 동작 부품(`react-native-gesture-handler`)이 앱에 없어 새 APK가 필요하고, 한 번에 하나만 지울 수 있으며 목록을 넘기다 실수하기 쉽다.

## 변경 사유
분석이 쌓이면 지워야 하는데 지금은 줄마다 길게 눌러 하나씩만 지울 수 있고, 길게 누르기는 알아채기 어렵다(최혜지 요청).

## 영향
- 서버 API는 바뀌지 않았다. 여러 건을 지우면 요청이 건수만큼 간다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(128개 통과, 추가: `deletable`, 고르는 중인 행의 체크 상태·길게 눌러도 안 지움, 분석 중 행은 고를 수 없음). 웹 빌드로 ⋯ 메뉴, 고르기, 확인 창, 모두 지우기 확인 창을 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
