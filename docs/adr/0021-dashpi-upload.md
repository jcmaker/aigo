# 0021. DashPi 기기 클립을 AIGO에 올린다

- 상태: 채택
- 날짜: 2026-11-08
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 `docs/superpowers/specs/2026-11-08-dashpi-upload-design.md`, PR #49, #50

## 작업 내용
- DashPi에서 사고 버튼을 누르면 기존 동작(Pi 자체 분석, 레포트, 광학 QR)과 함께 사고 클립을 AIGO에 올립니다. 둘은 서로를 기다리지 않습니다.
- 서버에 새 업로드 API는 만들지 않고 웹·앱과 같은 3단계 API를 씁니다.
- Pi는 사용자 계정에 묶인 Clerk API Key로 인증합니다. API Key는 분석 생성과 제출 두 경로에서만 받습니다.
- `analyses.source` 열(`upload`/`dashpi`, 마이그레이션 0006)을 더했습니다. 값은 클라이언트가 아니라 인증 방식으로 정합니다. 웹과 앱은 DashPi 배지를 보입니다.
- 동의, 하루 한도, 크기 제한, 완료 푸시는 기존 규칙 그대로입니다.

## 변경 사유
- 캡스톤 시연에서 "DashPi 블랙박스 → AIGO 서비스"가 실제로 이어지는 것을 보이려는 것입니다(조준형 결정).
- 조준형이 "기존 기능들은 그대로 작동, 추가만", "그냥 동시에 일어나는 거"라고 정했습니다.
- Pi 키로 삭제, 결제, 계정 정보에 접근하면 안 됩니다. 배지를 웹 사용자가 흉내 내면 안 됩니다.

## 영향
- 인증 서비스 장애는 401이 아니라 503(`AUTH_PROVIDER_UNAVAILABLE`)입니다.
- 키 발급은 관리자가 스크립트로 합니다(README).
