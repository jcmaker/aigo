# 0012. 과실 기준은 과실비율정보포털 도표

- 상태: 채택
- 날짜: 2026-11-05
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 2026-11-05 5장, PR #7, #43

## 작업 내용
- 손해보험협회 과실비율정보포털의 도표를 과실 기준 원천으로 씁니다(`apps/api/data/fault_charts.json`, 24개).
- 도표마다 출처 URL을 저장해 레포트에 링크합니다.
- 맞는 도표가 없으면 사고 분석은 보여 주고 과실비율은 "기준 도표를 찾지 못했습니다"로 표시합니다.
- `involvement`가 `witness`(제3자 사고)면 분석만 보이고 과실비율은 비웁니다. `none`이면 이유만 보입니다.

## 변경 사유
- 공신력 있는 공개 기준을 써야 레포트를 믿을 수 있습니다.
- 기존 `accident-counsel`의 기준 표는 8개뿐이라 평가 세트에 나오는 사고 유형으로 늘렸습니다.

## 영향
- 협회의 "기본 과실 해설" 글은 저작권이 있어 옮기지 않습니다(ADR 0014).
