# 0025. 사고 현장 모드를 질문 카드형 상황 안내로 바꾸고, 화면 색을 다듬고, 앞선 앱 디자인 변경을 기록한다

- 상태: 제안

- 변경 작업자: 최재혁 (DALRAMGI), Claude(AI) 사용

## 작업 내용
### 이번 변경: 사고 현장 모드 질문 카드형 안내 (`apps/app`)
- 고정 체크리스트 6줄(`SceneBody.tsx`의 `CHECKLIST`)과 맨 위 112·119 버튼 두 개를 없앴다.
- 오른쪽 위에 빨간 **신고** 버튼(느낌표 아이콘)을 두었다. 누르면 아래에서 창이 올라와 112 경찰 / 119 구급·소방을 고르고, 폰의 전화 앱이 그 번호로 열린다.
- 그 자리에 **질문 카드**(`SceneGuide`)를 두었다. 파랑과 하늘색 사이의 차분한 색(`sceneCard` #5580C8) 카드에 흰 제목, 흰 답 상자에 검은 글자와 아이콘을 쓴다.
  - 머리줄: 뒤로(이전 질문), 가운데 "사고 안내", 오른쪽 단계(1 / 7), 아래 진행 막대
  - 시작 카드: 사고 표지판 그림(`CrashSign`), "도움이 필요하신가요?", 한 줄 안내, 오른쪽 아래 화살표 버튼
- 질문 순서(`src/lib/scene-guide.ts`의 `nextQuestion`)
  1. 도움이 필요하신가요? (시작)
  2. 무엇과 부딪혔나요? 두 칸 격자 8개: 다른 차 / 사람 / 이륜 이동수단 / 주차된 차 / 고정물 / 동물 / 도로 상태 / 기타. 칸마다 아이콘 틀, > 동그라미, 이름과 설명 한 줄
  3. 어떻게 부딪혔나요? (다른 차, 이륜만): 내가 가서 / 나는 멈춰 있는데 상대가 와서 / 둘 다 움직이는 중 / 기타
  4. 도로가 어땠나요? (도로 상태만): 갈라졌어요 / 떨어져 있던 물체 / 기타
  5. 연기가 나거나 불이 보이나요? "네"면 바로 대피 안내만 보여 주고 끝낸다
  6. 다친 사람 → 장소(고속도로 / 일반 도로 / 주차장·골목) → 상대방 상태(차·사람·이륜·기타만) → 차를 움직일 수 있는지
- "기타"를 고르면 글 입력칸이 열린다("단어로 입력해 주세요"). 비워도 넘어갈 수 있고, 적은 말은 결과 위쪽 요약 칩에 다른 특징과 함께 나온다.
- 결과: 요약 칩(장소, 상대, 방식, 다친 사람), **지금 할 일**(안전 → 구조·신고 → 기록 → 정보 → 차 → 보험), **사고 뒤 할 일**.
  - 단계마다 표지판처럼 읽히는 아이콘을 둔다. 아이콘을 누르면 완료, 제목을 누르면 자세한 방법과 바로가기(112, 119, 도로공사 1588-2504, 보험사, 현장 사진)가 열린다.
  - 급한 단계는 줄 전체를 연분홍 상자로 감싼다.
  - 상황별 예: 고속도로 대피(비트밖스)와 무료 긴급견인, 받힌 경우 상대 보험사 접수 요청과 직접 청구, 뺑소니·음주·다툼은 112, 동물은 만지지 않기, 도로 파손은 도로 관리 주체에 배상 청구, 낙하물·무보험은 정부보장사업(1544-0049)
- 파일:
  - `src/lib/scene-guide.ts`(질문과 안내 규칙)
  - `src/components/SceneGuide.tsx`(질문 카드와 결과)
  - `src/components/CrashSign.tsx`(표지판 그림)
  - `src/components/SceneBody.tsx`(신고 버튼과 창)
  - `src/components/ui/Icon.tsx`(아이콘 추가)
  - `src/theme.ts`(`sceneCard` 색)
  - 테스트: `src/lib/scene-guide.test.ts`, `src/components/scene.test.tsx`

### 이번 변경: 화면 바탕과 영상 분석하기 카드 색 (`apps/app`)
- 바탕색 토큰 `bg`(#EBEBEB)를 추가하고 `Screen`의 바탕을 `gray3`(#F0F0F0)에서 `bg`로 바꿨다. 모든 화면 바탕이 아주 살짝 어두워져 흰 카드(#FFFFFF)가 또렷해진다.
- 영상 분석하기(`src/app/(tabs)/upload.tsx`)의 "어떤 영상을 분석할까요?" 카드를 흰색에서 앱 파랑(`brand`)으로 바꿨다. 홈의 "사고 영상, 바로 분석해요" 카드, 하단 메뉴 영상 버튼과 같은 색이다. 이를 위해 `EmptyState`에 `tone="brand"`를 추가했다(기존 사용처는 그대로).

### 앞선 변경(PR #53으로 이미 dev에 머지됨)

- 앱 색을 채도를 낮춘 파랑(#3A64C4)·남색(#1A2B4C)으로 시험 적용, `onBrand` 토큰 추가
- 홈 A안: DashPi 기기 카드(준비 중, 연결 점), 사고 났어요 / 분석 결과 두 갈래, "사고 영상, 바로 분석해요" 메인 카드, 오른쪽 위 알림 버튼
- 알림 화면(`/notifications`): 완료·실패한 분석을 알림으로 표시, 읽음은 폰에만 저장
- 현장 모드 '알릴 사람' 카드: 가족·지인 연락처 최대 5명, 전화·문자, 폰에만 저장

## 변경 사유
- 앱 디자인 담당(최재혁)이 디자인 결과를 최종 개발자(조준형)에게 전달하기 위한 변경이다.
- 기존 체크리스트는 모든 사고에 같은 6줄을 보여 줘서 허술해 보였다(최재혁 발견). 경미한 접촉사고에도 119를 안내했고, 사람·동물·시설물·도로 파손 사고나 받힌 사고처럼 상황마다 다른 할 일을 담지 못했다.
- 한 화면에 모두 쓰면 세부를 놓치기 쉬워, 질문 카드에 하나씩 답하면 앱이 모아서 안내하게 했다. 사고 직후라 눈이 편하고 한눈에 읽히도록 아이콘과 차분한 색을 썼다.
- 바탕과 흰 카드의 차이가 작아 카드가 또렷하지 않았고, 영상 분석하기 첫 카드가 홈의 파란 분석 카드와 같은 기능처럼 보이지 않았다.
- 안내 근거:
  - 도로교통법 제54조(사고 후 조치, 물적 피해만이고 안전하게 치웠으면 신고 의무 없음)
  - 보험사 약관의 사고 대처 요령(사진·스프레이 표시·목격자, 차를 옮기고 시동 끄기)
  - 금융감독원 안내(견인은 보험사 먼저, 렌터카 권유 주의, 렌트비 35% 교통비 현금 대체, 합의는 신중히)
  - 한국도로공사 2차 사고 예방 행동요령(비트밖스)과 긴급견인 1588-2504
  - 시설물 파손 시 신고와 대물 접수(서울시설공단)
  - 동물 찻길 사고 신고(정책브리핑: 고속도로 1588-2504, 그 밖은 지역번호+120/128)
  - 정부보장사업(1544-0049, 3년 안 신청)
  - 국가배상법 제5조(도로 하자 배상)
  - 손해보험협회 신속처리 협의서
  - 안전삼각대는 현재 정해진 거리 기준이 없어 "뒤차가 충분히 볼 수 있는 곳, 도로 위를 무리하게 걷지 않기"로 안내한다.

## 영향
- 현장 모드는 여전히 로그인·인터넷 없이 동작한다(규칙으로만 안내, AI 호출 없음).
- 112·119는 오른쪽 위 신고 버튼에서 한 번 더 골라야 한다. 대신 어느 질문을 보고 있든 같은 자리에 있다.
- 완료 체크와 기타 입력은 화면을 벗어나면 초기화된다(저장하지 않음).
- 확인: `pnpm exec tsc --noEmit` 통과, `pnpm test` 104개 통과. 웹 미리보기로 화면을 확인했다. Android 실기기·개발 빌드 확인은 하지 못했다.
- 남은 일: 안내 문구는 법률·의료 자문을 받지 않은 일반 안내다. 필요하면 전문가 검토를 받는다.
