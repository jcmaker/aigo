# 0046. 리포트 요약 탭은 내 과실 범위가 담긴 요약 카드를 맨 위에 둔다

- 상태: 제안
- 날짜: 2026-11-23
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #99

## 작업 내용
- `components/analysis.tsx` 요약 탭 순서: 지금 먼저 할 일 → 사고 분석 요약(남색, 내 과실 범위) → … 에서 사고 분석 요약 → 지금 먼저 할 일 → 영상에서 확인한 장면 → … 로 바꿨다(ADR 0027의 순서를 고침). 내용은 그대로다.

## 변경 사유
리포트에서 가장 중요한 내 과실 범위가 "지금 먼저 할 일"에 밀려 첫 화면 아래 끝에 걸렸다(최혜지 확인). 리포트는 영상을 올리고 분석이 끝난 뒤에 보므로 가장 궁금한 것은 과실 범위이고, 현장에서 급한 일(비상등, 112·119)은 사고 현장 모드가 상황별로 안내한다. 할 일을 접는 방법도 생각했지만, 접힌 안전 안내는 열어 보지 않기 쉬워 숨기지 않고 순서만 바꿨다. 기준 탭도 과실 범위부터 보인다.

## 영향
- 화면 순서만 바뀐다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(129개 통과, 요약 카드가 지금 먼저 할 일보다 먼저 보이는 테스트 추가). 웹 빌드로 요약 탭 첫 화면을 찍었다.
