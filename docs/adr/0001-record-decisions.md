# 0001. ADR로 변경 사유와 작업자를 남긴다

- 상태: 채택 (PR 양식 부분은 0006으로 대체)
- 날짜: 2026-11-09
- 변경 작업자: 조준형 (jcmaker)
- 관련 PR: 가드레일 PR

## 작업 내용
- `docs/adr/`에 ADR 양식(`0000-template.md`)과 목록(`README.md`)을 둡니다.
- 관리자가 아닌 사람의 PR은 ADR 파일을 하나 추가해야 합니다. CI의 "PR 가드레일" 검사가 확인합니다.
- PR 양식에 작업 내용, 변경 사유, 작업자 칸을 둡니다. CI가 빈칸을 확인합니다.
- AI 도구(Claude Code, Codex 등)가 읽는 `AGENTS.md`와 `CLAUDE.md`에 같은 규칙을 적습니다. AI는 작업 전에 변경 사유와 작업자를 묻습니다.

## 변경 사유
캡스톤 팀원(비개발자)이 수정에 참여하기 시작합니다. 여러 사람이 고치면 왜 바뀌었는지, 누가 바꿨는지 알기 어렵습니다. 조준형이 변경마다 작업 내용, 변경 사유, 작업자를 남기도록 요청했습니다.

## 영향
- 팀원의 작은 수정에도 ADR 파일이 하나씩 생깁니다.
- 관리자(jcmaker)의 PR은 이 검사에서 제외합니다.
