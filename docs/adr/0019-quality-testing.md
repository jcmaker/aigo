# 0019. 분석 품질 테스트는 에뮬레이터 없이, 비용 25달러 안에서

- 상태: 채택
- 날짜: 2026-11-08
- 변경 작업자: 조준형 (jcmaker)
- 관련: `docs/analysis-quality.md`, PR #40~#46

## 작업 내용
- 분석 품질 개선 작업은 평가 도구(`python -m app.evaluate`), pytest, 웹·API로만 확인합니다. Android 에뮬레이터는 쓰지 않습니다.
- 품질 측정에 쓰는 OpenAI 비용은 25달러를 넘지 않게 합니다. `--budget`으로 막고, 다시 채점(`--rescore`)은 비용 없이 합니다.
- 정답 라벨은 Claude가 만든 초안 정답으로 진행하고, 모든 결과에 "초안 정답 기준"이라고 적습니다.

## 변경 사유
- 분석은 worker에서 돌아서, 개선되면 웹과 앱 모두 좋아집니다. 앱을 거칠 필요가 없습니다.
- 조준형이 "품질 개선 작업 테스트할 때는 에뮬레이터 사용하지 말 것", "테스트 토큰 비용 25달러를 넘기지 않는 선"이라고 정했습니다.
- 팀의 정답 확인을 기다리면 작업이 멈춥니다.

## 영향
- 2026-11-08 품질 작업의 OpenAI 비용은 약 5.3달러였습니다.
- 초안 정답과 Claude가 판정한 근거 26개는 아직 사람이 확인하지 않았습니다.
