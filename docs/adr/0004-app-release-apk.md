# 0004. 앱은 GitHub Releases APK로 배포한다

- 상태: 채택
- 날짜: 2026-11-09 (결정은 2026-11-07)
- 변경 작업자: 조준형 (jcmaker)
- 관련 PR: #48, #52

## 작업 내용
- Android 앱은 GitHub Releases에 서명한 APK로 올립니다(v0.1.0 ~ v0.3.1).
- 새 버전마다 `apps/app/app.json`의 `version`과 `android.versionCode`를 PR로 올린 뒤 빌드합니다.
- 모든 버전을 같은 서명 키로 서명해서 기존 설치 위에 업데이트되게 합니다. 서명 키는 관리자만 가집니다.

## 변경 사유
Play 스토어와 앱 스토어 등록은 시간과 비용이 듭니다. 캡스톤과 수업 시연에는 APK 직접 설치로 충분합니다.

## 영향
- 릴리즈는 관리자만 할 수 있습니다.
- iOS와 스토어 배포는 나중에 결정합니다.
