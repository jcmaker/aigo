# 0018. 앱 디자인: Supabase 색, TennisIQ 하단 메뉴, 없는 기능은 만들지 않는다

- 상태: 채택
- 날짜: 2026-11-08
- 변경 작업자: 조준형 (jcmaker), Claude(AI) 디자인 시스템 설계
- 관련: 설계 `docs/superpowers/specs/2026-11-08-aigo-app-ui-design.md`, PR #32~#38, #51

## 작업 내용
- 색은 Supabase 공식 테마 값을 씁니다(`apps/app/src/theme.ts`). 로고도 Supabase 색으로 바꾼 버전을 씁니다(`apps/app/scripts/brand.py`).
- 하단 메뉴는 TennisIQ처럼 떠 있는 알약 모양이고 5개 탭입니다: 홈, 내 분석, 분석하기, 현장 모드, 계정.
- 토스 앱의 회색 바탕 위 흰 카드, 큰 숫자와 짧은 문장을 참고했습니다.
- 앱을 열면 로고 "길 그리기" 모션(약 1.4초)을 보여 줍니다. 모션 중에도 현장 모드 버튼은 누를 수 있습니다.
- 홈, 내 분석, 계정 화면은 조준형이 준 DashPi HTML 시안의 배치를 따릅니다(PR #51).
- 시안에 있어도 앱에 없는 기능(기기 연결, 프로필 수정, 앱 설정, 도움말, 예시 데이터)은 만들지 않습니다.

## 변경 사유
- 조준형이 "AI가 만든 티가 나는 화면"을 피하려고 dribbble, Mobbin, UIBowl, 토스를 직접 조사하게 했고, 그중 TennisIQ를 골랐습니다.
- 색은 Supabase 팔레트로 정했습니다(조준형 결정).
- 조준형이 "없는 것은 추측하거나 스스로 기획해서 만들지 말 것"이라고 정했습니다.

## 영향
- 다크 모드와 별도 글꼴은 넣지 않았습니다.
- 시안의 DashPi 기기 탭 자리는 사고 현장 모드가 씁니다.
