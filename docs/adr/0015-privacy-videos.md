# 0015. 영상과 개인정보 처리

- 상태: 채택
- 날짜: 2026-11-05
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 2026-11-05 5장, `apps/api/app/routes/me.py`, CONTRIBUTING

## 작업 내용
- 업로드 화면에서 "번호판과 얼굴이 담길 수 있고, 프레임이 OpenAI로 전송된다"를 알리고 동의를 받습니다(`consent=true`).
- Bucket은 비공개이고, 재생은 1시간짜리 서명 URL로만 합니다.
- 분석을 삭제하거나 탈퇴하면 영상 파일까지 지웁니다. 탈퇴 때 분석 내용은 지우되 행은 `user_id` 없이 남겨 하루 한도 집계를 보존합니다.
- 사고 영상(`사고영상/`, 평가 영상)은 공개 저장소와 공개 페이지에 올리지 않습니다. 랜딩의 레포트 예시는 실제 분석 결과의 글만 쓰고 "예시"로 표시합니다.

## 변경 사유
- 사고 영상에는 다른 사람의 얼굴과 차량 번호가 담깁니다.
- 저장소가 공개라 한 번 올린 파일은 기록에 남습니다.
- 탈퇴한 뒤 다시 가입해 하루 한도를 피하는 것을 막아야 합니다.

## 영향
- 비밀값과 비밀 파일은 비밀값 검사가 막습니다(ADR 0005).
