# 0017. 모바일 앱: Expo 한 코드, 오프라인 현장 모드

- 상태: 채택
- 날짜: 2026-11-06
- 변경 작업자: 조준형 (jcmaker) 결정, Claude(AI) 세부 설계 후 조준형 승인
- 관련: 설계 `docs/superpowers/specs/2026-11-06-aigo-app-design.md`, PR #22~#30

## 작업 내용
- 웹이 책상에서 보는 도구라면 앱은 사고 직후 현장에서 쓰는 도구입니다.
- iOS와 Android를 한 코드(Expo)로 만듭니다. 웹과 같은 `/api/v1`과 OpenAPI 타입을 씁니다.
- 앱 기능: 로그인, 영상 업로드와 구간 자르기, 분석 진행과 레포트, 레포트 PDF 공유, 분석 완료 푸시, 다른 앱의 공유 메뉴로 영상 받기, 사고 현장 모드.
- 사고 현장 모드는 로그인 없이, 인터넷 없이 동작합니다. 체크리스트, 112·119·보험사 전화, 시각과 위치가 붙은 현장 사진. 기록은 폰에만 둡니다.
- 상품 구매는 앱에 새로 만들지 않고 웹 페이지를 엽니다.

## 변경 사유
- 사고 직후에는 로그인이나 네트워크를 기다릴 여유가 없습니다.
- 앱 하나로 두 플랫폼을 맞추고, 웹과 같은 API를 써서 서버를 바꾸지 않으려는 것입니다(조준형 결정).

## 영향
- 앱을 닫아도 계속되는 백그라운드 업로드는 하지 않습니다.
- iOS 빌드는 Xcode와 유료 Apple 계정이 필요해 나중에 합니다. 배포는 ADR 0004.
