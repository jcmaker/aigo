# 0028. 홈 화면을 남색·민트로 맞추고 글씨를 키우며, 앱 바탕을 남색 기운의 밝은 회색으로 바꾼다

- 상태: 제안
- 날짜: 2026-11-14
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #번호

## 작업 내용
메인화면 글씨크기 수정작업및 레이아웃, 색감조정 등.

- 홈(`app/(tabs)/home.tsx`)
  - 큰 "사고 영상, 바로 분석해요" 카드를 파랑(`brand`)에서 남색(`ink`)으로 바꾸고 포인트를 민트로 했다. 카메라 아이콘은 민트, 버튼은 민트 바탕에 남색 글씨(새 버튼 종류 `mint`, 대비 7.05:1).
  - "분석 결과" 카드 아이콘을 파랑에서 민트(`mintSoft` 바탕, `mintDeep` 아이콘)로 바꿨다. "사고 났어요" 빨간 카드는 그대로다.
  - 작은 글씨를 키웠다: 카드 설명 13 → 15px, 형식 안내(mp4, mov…) 11.5 → 13px. 제목 크기는 그대로다.
  - 아직 "준비 중"인 DashPi 기기 카드를 맨 위에서 맨 아래로 옮겼다. 사고 났어요·분석 결과가 첫 줄에 온다.
- 앱 전체 바탕(ADR 0018의 회색 바탕을 바꿈)
  - `color.bg`를 `#EBEBEB`에서 `#F3F5F8`(남색 기운의 밝은 회색)로 바꿨다. 리포트 화면에만 쓰던 `reportBg`(#F4F7F9)는 없애고 같은 바탕을 쓴다.
  - 바탕과 흰 카드의 차이가 줄어서 흰 카드·흰 동그라미 버튼·탭에 1px 테두리 `color.line`(#E6E9EF)을 넣었다: `Card`, `MenuGroup`, `SegmentedControl`, `TopBar` 버튼, 홈 카드, 계정 카드, 알림 목록, 현장 안내 요약 카드.
  - 바탕이나 카드 위의 흐린 작은 글씨 `gray9`(바탕 대비 3.04:1)를 `gray11`(5.42:1)로 바꿨다: 계정 화면 앱 버전, 알림 시간.

## 변경 사유
글씨사이즈 작은것 같음, uxui 건들고 싶음 - 최혜지

분석 리포트(ADR 0027)를 남색·민트로 바꾼 뒤 홈은 파랑·회색이라 앱 안 색감이 따로 놀았다. 앞서 보류한 "앱 바탕을 네이비 기운의 밝은 회색으로"(수정 1)도 이번에 함께 반영해 달라는 요청(최혜지)이 있었다.

## 영향
- ADR 0018(앱 디자인, 조준형)의 "회색 바탕 위 흰 카드"를 바꾸는 결정이라 조준형의 검토가 필요하다.
- 기능, 화면 이동, 서버 API는 바뀌지 않았다. 홈의 DashPi 카드는 위치만 바뀌었다.
- 대비: 남색 카드 위 설명 글씨(#9DB4E6) 6.76:1, 바탕 위 gray11 5.42:1, 민트 버튼 남색 글씨 7.05:1. "사고 났어요" 빨간 카드의 글씨 대비(흰 글씨 3.87:1, 설명 3.49:1)는 원래부터 4.5:1에 못 미치며 이번에는 색을 바꾸지 않았다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(108개 통과). 웹 빌드로 홈 화면 전·후를 390px·320px에서 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
