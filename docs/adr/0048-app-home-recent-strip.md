# 0048. 홈 "최근 분석"을 제목 줄 없는 한 줄 띠로 줄여 맨 위에 붙인다

- 상태: 제안
- 날짜: 2026-11-23
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #99

## 작업 내용
- `app/(tabs)/home.tsx`: 묶음 제목 줄("최근 분석" + "전체 보기")과 큰 분석 카드 대신 한 줄 띠(`components/AnalysisRow.tsx`의 `RecentStrip`)를 로고 바로 아래에 둔다.
- 띠: 왼쪽 상태 아이콘, 가운데 "최근 분석 · 날짜"(13px)와 사고 이름 한 줄(15px, 길면 말줄임), 오른쪽 내 과실 범위(완료) 또는 상태 칩(분석 중·실패), 화살표. 누르면 그 리포트로 간다.
- "전체 보기"는 뺐다. 하단 메뉴 "내 분석"과 같은 곳으로 간다. 쓰지 않게 된 `RecentAnalyses`를 지웠다.
- 보이는 조건(가장 최근 1건, 올린 지 14일 안, ADR 0034)은 그대로다.

## 변경 사유
로고와 최근 분석 사이 제목 줄이 자리를 차지해 메인인 영상 분석 카드가 아래로 밀렸다(최혜지 요청). 홈에서는 분석이 끝났는지와 과실 범위만 보이면 충분하다.

## 영향
- 최근 분석 부분 높이가 약 160 → 70(웹 미리보기 기준)으로 줄어 영상 분석 카드가 올라온다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(130개 통과, 띠 테스트 2개로 바꿈: 완료면 과실 범위·누르면 리포트로, 분석 중이면 상태 칩). 웹 빌드로 분석 중·완료 홈을 찍었다.
