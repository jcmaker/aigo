# 0031. 내 분석이 비어 있을 때 무엇을 받는지와 영상 찾는 법을 안내한다

- 상태: 제안
- 날짜: 2026-11-14
- 변경 작업자: 최혜지 (marong9087), Claude(AI)
- 관련 PR: #번호

## 작업 내용
내 분석창 UX/UI 수정: 영상을 아직 올리지 않은 상태(분석 0건)의 화면(`app/(tabs)/analyses.tsx`).

- 분석이 0건이면 필터(전체·완료·진행 중)와 "분석 목록 0건" 줄을 숨긴다. 눌러도 화면이 바뀌지 않기 때문이다.
- 빈 화면을 세 덩어리로 바꿨다.
  - 남색 카드: "아직 분석한 사고가 없어요", "블랙박스 영상을 올리면 과실 범위와 근거 장면을 정리해 드려요.", 흰 "영상 올리기" 버튼(홈과 같은 `onDark`).
  - "이렇게 진행돼요" 3단계: 영상 올리기(사고 앞뒤가 담긴 2분 이하 영상) → AI가 장면 분석(끝나면 알림) → 리포트 받기(과실 범위 · 근거 장면 · PDF). 번호는 민트.
  - 접히는 "블랙박스 영상, 어떻게 찾나요?": 제조사 앱, 메모리카드, "충격·이벤트" 폴더, 2분 이하, 원본 보관. 블랙박스마다 다르므로 "대부분", "보통"처럼 단정하지 않는다.
- 분석은 있는데 필터 결과가 0건이면 필터에 맞춰 "완료된 분석이 없어요", "진행 중인 분석이 없어요"를 보인다(전에는 모두 "해당하는 분석이 없어요").
- 분석 시간("몇 분")은 확인한 값이 없어 쓰지 않았다.

## 변경 사유
내 분석창 UX/UI 수정 - 최혜지

빈 화면이 "아직 분석한 영상이 없어요"와 파란 버튼뿐이라, 처음 온 사람은 무엇을 받는지 모르고 사고 직후인 사람은 영상을 어떻게 꺼내는지 몰라 막혔다. 세 가지 방향(안내형·준비형·간결형) 중 안내형에 영상 찾는 법을 접어 넣는 안을 골랐다.

## 영향
- 분석이 1건 이상일 때의 목록 모양은 바꾸지 않았다(다음 작업).
- 기능과 서버 API는 바뀌지 않았다.
- 확인: `pnpm exec tsc --noEmit`, `pnpm test`(108개 통과). 웹 빌드로 빈 화면(접힘·펼침), 320px, 필터 결과 0건을 찍었다. 실제 안드로이드 기기에서는 아직 보지 않았다.
