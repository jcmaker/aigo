# DashPi 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 랜딩, 상품 구매, Clerk 회원 기능, AI 사고분석이 Railway에서 처음부터 끝까지 동작하는 DashPi 웹 서비스를 만든다.

**Architecture:** FastAPI가 `/api/v1` 계약을 제공하고 Next.js 웹은 첫 번째 클라이언트로 Bearer 토큰을 보낸다. 분석은 Postgres 대기열을 쓰는 별도 worker가 처리하고, 영상은 비공개 S3 호환 Bucket에 저장한다. 분석 파이프라인은 충돌 구간을 먼저 찾고, 관찰과 판단을 나누고, 과실 숫자는 코드로 계산한다.

**Tech Stack:** Python 3.12, uv, FastAPI, SQLAlchemy 2, Alembic, Postgres, boto3, FFmpeg, ultralytics, OpenCV, OpenAI SDK, clerk-backend-api, Next.js 16 App Router, TypeScript, Tailwind v4, @clerk/nextjs 7, @tosspayments/tosspayments-sdk 2, openapi-typescript, pytest, vitest, Playwright, Railway.

**Spec:** `docs/superpowers/specs/2026-11-05-dashpi-design.md`

> 구현 중 폴더가 바뀌었다: `backend/`는 `apps/api/`, `frontend/`는 `apps/web/`이다. 서비스 이름은 AIGO, DashPi는 상품명이다.

## Global Constraints

- 사용자에게 보이는 문구와 코드 주석은 한국어로 쓴다.
- 모든 API 경로는 `/api/v1`로 시작한다. 오류는 항상 `{"code": "...", "message": "한국어 문장"}`이다.
- 목록은 `?limit=&offset=`을 받고 `{"items": [...], "total": n}`을 돌려준다. 시간은 UTC ISO 8601, 금액은 원 단위 정수다.
- 다른 사용자의 주문이나 분석은 403이 아니라 404로 응답한다.
- Clerk 기본 UI 컴포넌트(`<SignIn/>`, `<SignUp/>`, `<UserProfile/>`, `<UserButton/>`)는 쓰지 않는다. 모든 인증 화면은 DashPi 디자인 시스템으로 만든다.
- 영상 제한 기본값: mp4, mov, webm, avi, 200MB, 2분. 사용자당 하루 5건, 서비스 전체 하루 100건. 하루는 한국 시간 기준이고 `failed`는 세지 않는다. 모두 환경변수로 조정한다.
- 서명 업로드 URL은 15분, 재생 URL은 1시간이다. Bucket은 비공개다.
- 시크릿 키는 서버 환경변수에만 둔다. 서버는 `test_`로 시작하지 않는 Toss 키를 받으면 시작하지 않는다.
- 체크아웃과 주문 화면에 "테스트 결제입니다. 실제로 청구되지 않습니다"를 표시한다.
- 모든 레포트 화면에 "영상 기반 AI 추정이며 법적 판단이 아닙니다"를 화면 코드로 고정한다.
- 지어낸 후기, 고객 수, 정확도 수치를 쓰지 않는다. 푸터에 캡스톤 가상 서비스임을 표시한다.
- `video_ai`, `accident-counsel`의 코드, 화면, 문구를 복사하지 않는다. ArtCraft의 로고, 이미지, 문구를 쓰지 않는다.
- `사고영상/` 클립은 저장소와 공개 페이지에 넣지 않는다.
- `prefers-reduced-motion`을 존중하고, 키보드 포커스를 표시하고, 360px 폭에서 가로 스크롤이 없어야 한다.

## Review Focus

1. 업로드가 끊겼는데 `submit`이 호출되는 경우: 파일이 없거나 크기가 다르면 `409 UPLOAD_INCOMPLETE`이고 대기열에 넣지 않는다. (Task 5)
2. 토스 승인 요청 중 네트워크 오류 후 새로고침: 주문은 `pending`을 유지하고, 같은 `Idempotency-Key`로 재시도해 이중 승인되지 않는다. (Task 4)
3. 확장자만 mp4인 파일, 소리 없는 영상, 세로 영상, 회전 메타데이터가 있는 영상: 앞의 것은 `INVALID_VIDEO`로 실패하고, 나머지는 정상 처리한다. (Task 7)
4. 분석 중 삭제 또는 탈퇴: worker가 끝난 뒤 행이나 파일을 되살리지 않는다. (Task 6)
5. 분석 화면을 오래 열어 둔 경우: 만료된 Clerk 토큰으로 폴링이 끊기지 않고, 401이면 새 토큰으로 한 번 재시도한다. (Task 12)
